# Orar

Aplicație web/PWA pentru orarul C_11/1.

- Editare ore, materie, profesor și locație
- CURS / SEMINAR / LABORATOR
- MEREU / PARĂ / IMPARĂ
- Notițe simple pe fiecare activitate
- Termen calendaristic opțional pentru notițe
- Punct alb cât timp există ceva de făcut
- Punct portocaliu în ziua termenului
- Punct roșu după depășirea termenului
- Salvare locală pe fiecare dispozitiv
- Responsive pentru iPhone și desktop
